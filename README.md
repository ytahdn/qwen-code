# Browser action notification UI evidence

Captured on macOS using isolated Playwright Chromium against Web Shell source.
The daemon and Notification API were mocked. These screenshots show rendered
approval/question UI and notification help; they do not validate native OS
notification banners or real backend approval execution.

浏览器截图来自 macOS 上隔离运行的 Playwright Chromium，使用模拟 daemon 和
Notification API。截图展示审批／问答浮窗及通知说明，不证明系统通知实际展示或
真实后端审批执行。
